# Big Data Project — complete repository

This repository contains the complete academic project:

- `earthquake_bigdata/` — source code, configs, tests, downloaded raw data,
  processed Parquet, analytics results, benchmarks and Streamlit dashboard.
- `papers/` — reference papers used in the literature survey.
- `Project_Abstract.docx` — project abstract.
- `Team4_Literature_Survey_Earthquake.pptx` and
  `Team4_Literature_Survey_Volcano.pptx` — literature survey decks.

Start with:

- `DEMO_GUIDE.md` — exact 10–15 minute walkthrough for the teacher
- `CORRECTIONS_APPLIED.md` — factual corrections applied to the paper/slides
- `earthquake_bigdata/README.md`
- `earthquake_bigdata/PROJECT_STATUS.md`
- `earthquake_bigdata/docs/RESULTS.md`

Notes:

- The virtual environment (`.venv`), logs, and generated `data/benchmark/`
  scratch copies are excluded; recreate them with `requirements.txt` and the
  documented commands.
- Raw and processed project datasets are included because they are part of the
  research deliverable.
- The former nested Git history is backed up outside the repository; this root
  repository tracks the complete project in one place.
